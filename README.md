# ▶️ How to Run the Project

## Method 1 — Open Directly

1. Download or clone the repository.
2. Open the `project` folder.
3. Open:

```text
index.html
```

4. The dashboard will open in your web browser.
5. Select HTML, CSS, or JavaScript to explore the programs.

---

## Method 2 — Using Visual Studio Code

1. Open the repository in **Visual Studio Code**.
2. Open the `project` folder.
3. Open:

```text
project/index.html
```

4. Use the **Live Server** extension if available.
5. Open the website in your browser.

---

# 📥 Clone the Repository

Use the following command to clone the repository:

```bash
git clone https://github.com/suhaassarabu/frontend_website.git
```

Then enter the project folder:

```bash
cd frontend_website
```

Open the `project` folder and run `index.html`.
